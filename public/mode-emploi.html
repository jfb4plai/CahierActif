CahierActif : mode d'emploi

Annoter une fiche ou une photo comme sur un cahier.

  • Pour l'élève
  • Pour l'enseignant
  • Ce que l'outil ne fait pas

CahierActif est une application qui s'ouvre dans le navigateur d'une tablette ou d'un ordinateur. Elle aide l'élève qui écrit ou trace difficilement à travailler sur une fiche numérique : écrire, dessiner, poser une opération, tracer avec une règle. Elle compense le geste. Elle ne vérifie rien et ne propose aucune réponse.

Gratuit, sans compte. Les documents restent sur l'appareil. Le code de l'application ne contient aucun envoi de document ou de donnée vers un serveur (recherche faite dans le code le 26/11/2026).

Pour l'élève

Les consignes de cette partie sont courtes. Une ligne, une action.

1. Ouvrir une fiche

Sur la première page, cinq grands boutons.

  • Ouvrir un PDF : choisir la fiche reçue de l'enseignant (Teams, Smartschool, mail).
  • Photographier une feuille : prendre en photo une feuille papier.
  • Choisir des photos : choisir plusieurs photos d'un coup. Une photo = une page.
  • Nouvelle page vierge : écrire sur une page blanche.
  • Reprendre un fichier .cahier : continuer un travail commencé sur un autre appareil.

Les documents se rangent dans des cours (Français, Mathématiques, Sciences, Histoire, Géographie, Langues). Le cours Exemple contient un document déjà annoté : devant chaque annotation, une ligne bleue donne la commande utilisée. Pour le supprimer : Retour à mes documents, puis Supprimer sur ce document.

Pour voir les documents d'un cours : toucher son nom. Ses documents s'affichent en premier, avec un bouton Ouvrir sur chacun. Toucher le titre ou la miniature ouvre aussi le document.

Pour supprimer un cours : toucher son nom, puis Supprimer ce dossier. Les documents du cours ne sont pas supprimés : ils passent dans « Sans dossier ». Le cours peut aussi être renommé.

Chaque document occupe une ligne : sa miniature (après sa première ouverture), son titre, sa date, puis quatre actions.

  • Ouvrir : ouvrir le document.
  • Renommer : changer son nom.
  • Ranger dans : choisir le cours dans la liste.
  • Supprimer : l'enlever de l'appareil.

Un titre long est coupé dans la liste. Le titre entier se lit en ouvrant le document, ou en touchant Renommer.

2. Écrire et dessiner

  1. Toucher Stylo.
  2. Choisir une couleur.
  3. Choisir Fin, Moyen ou Épais.
  4. Écrire sur la page.

Pour corriger :

  • Toucher Annuler pour défaire le dernier geste.
  • Toucher Gomme, puis un trait pour l'effacer en entier.
  • Toucher Gomme fine pour effacer une partie d'un trait.

Pour écrire au clavier : toucher Texte, puis la page.

Pour déplacer la page sans écrire : toucher Main.

Avec une tablette et un stylet, le doigt ne trace plus dès que le stylet a touché l'écran. Le doigt sert alors à faire défiler la page. La paume posée n'écrit pas.

3. Poser une opération

  1. Toucher Opération.
  2. Toucher la page à l'endroit voulu.
  3. Choisir +, −, × ou ÷ (en P1-P2 : + et − seulement).
  4. Choisir le nombre de colonnes et le nombre de nombres.
  5. Toucher Poser l'opération.
  6. Écrire les chiffres avec le pavé numérique.
  7. Toucher Terminé.

La page grossit pendant la saisie, puis revient à sa taille. Les colonnes unités, dizaines et centaines ont chacune leur couleur. L'application ne calcule rien.

4. Tracer avec une règle ou une équerre (à partir de P3)

  1. Dans la colonne de gauche, toucher Règle ou Équerre.
  2. Glisser l'instrument pour le déplacer.
  3. Glisser le rond avec la flèche circulaire pour le tourner. Avec deux doigts, tourner l'instrument directement.
  4. Choisir Stylo.
  5. Commencer le trait tout près d'un bord de l'instrument.
  6. Glisser le long du bord.

Le trait reste droit, le long du bord. Sa longueur s'affiche en centimètres. Pour retirer l'instrument, toucher son bouton une seconde fois.

Même principe pour le Rapporteur : le trait suit sa base. Les graduations vont de 0 à 180 dans les deux sens. L'élève lit l'angle lui-même.

Le compas

  1. Toucher Compas.
  2. Régler l'écartement avec les boutons de la fenêtre du bas.
  3. Glisser la croix (la pointe) à l'endroit du centre.
  4. Glisser le rond plein (la mine) autour de la pointe.

Un arc est tracé. Un tour complet donne un cercle.

5. Lire plus facilement (à partir de P3)

  • Loupe : un cercle agrandit ce qu'il recouvre. Le glisser pour le déplacer. Choisir ×2, ×3 ou ×4.
  • Cache-ligne : la page est cachée sauf 1 à 3 lignes. Glisser la partie sombre pour descendre d'une ligne à l'autre. Les boutons Monter et Descendre font la même chose.

Pour écrire sur une page quadrillée ou à lignes : ouvrir Plus d'options, puis choisir le fond de la page (quadrillé 5 mm, quadrillé 1 cm, Seyes ou pointé).

6. Finir et rendre son travail

  • Le travail est enregistré tout seul sur l'appareil.
  • Toucher Exporter en PDF pour rendre le travail ou l'imprimer. Les annotations ne se modifient plus ensuite.
  • Toucher Enregistrer un fichier .cahier pour continuer plus tard ou sur un autre appareil. Seul CahierActif rouvre ce fichier.
  • Toucher Retour à mes documents pour quitter le document.

Pour l'enseignant

Préparer une fiche

  • Envoyer la fiche en PDF à l'élève (Teams, Smartschool, mail). L'élève l'ouvre avec Ouvrir un PDF.
  • Un document de plus de 50 pages ne pose pas de problème de principe : les pages ne se chargent qu'à l'écran. Je ne l'ai pas mesuré sur tablette.
  • Un PDF protégé par mot de passe ou abîmé affiche un message clair au lieu de s'ouvrir.
  • Une feuille papier peut être photographiée : une photo devient une page.

Pour récupérer le travail : l'élève exporte en PDF (envoi par Teams ou mail) ou en fichier .cahier.

Installer l'application sur une tablette

Ouvrir l'adresse de l'application dans le navigateur, puis l'installer.

  • iPad (Safari) : toucher Partager, puis « Sur l'écran d'accueil ». Sans cela, l'iPad peut effacer les documents après quelques jours sans utilisation (c'est le message affiché par l'application).
  • Android (Chrome) : ouvrir le menu du navigateur, puis « Installer l'application » ou « Ajouter à l'écran d'accueil ». Le libellé exact dépend de la version.

L'icône est une tablette avec une page de cahier et un crayon orange. L'application est prévue pour s'ouvrir hors ligne une fois installée (non vérifié sur une vraie tablette).

Le mode verrouillé

Dans Réglages, choisir un code à 4 chiffres (le saisir deux fois), puis toucher Activer le mode verrouillé.

  • Le code est demandé pour ouvrir les Réglages.
  • Le code est demandé pour supprimer un document ou un dossier.
  • Une confirmation est demandée avant de quitter un document, et le navigateur avertit si l'onglet se ferme.
  • Pour désactiver : ouvrir les Réglages avec le code, puis toucher Désactiver le mode verrouillé.
Limite. Le code évite les erreurs et les jeux. Il ne protège pas contre quelqu'un qui efface les données du site : tout reste dans le navigateur de l'appareil. Une application web ne peut pas empêcher la fermeture du navigateur. Le travail est enregistré en continu, donc rien ne se perd.

Données et vie privée

  • Les documents sont enregistrés dans le navigateur de l'appareil, pas sur un serveur.
  • Pas de compte, pas de nom d'élève demandé.
  • Les instruments (règle, équerre, rapporteur, compas), la loupe et le cache-ligne ne sont pas enregistrés dans le document et n'apparaissent pas dans l'export.
  • Six cours et un cours « Exemple » (avec un document annoté) sont créés au premier lancement. Ils peuvent être supprimés ; ils ne reviennent pas.
  • Pour libérer de la place : supprimer le document dans la liste (le code est demandé si le mode verrouillé est actif).

Ce que l'outil ne fait pas

  • Il ne corrige pas et ne calcule pas : l'élève fait le raisonnement.
  • Il ne reconnaît pas l'écriture à la main.
  • Il ne lit pas le document à voix haute et ne permet pas la dictée vocale. Ce n'est pas encore prévu.
  • Il ne lit pas le texte d'une photo ou d'un PDF scanné (pas de reconnaissance de texte).
  • La barre P1-P2 n'a ni instruments, ni loupe, ni cache-ligne.
  • Le cache-ligne et la loupe recouvrent ce qu'on voudrait écrire dessous : les déplacer d'abord.
  • Le cache-ligne compte 10 mm par ligne : sur un texte à interligne très serré ou très large, la fenêtre ne tombera pas toujours juste.
État des essais (26/11/2026). L'application a été essayée à la souris dans un navigateur dont la fenêtre imite une tablette, par son auteur. Les instruments et la rotation à deux doigts ont aussi été essayés avec des gestes simulés. Elle n'a pas encore été essayée sur une vraie tablette avec un stylet, ni par un élève. Les retours de terrain sont bienvenus.
